# Каталог реакций NERV.
#
# Каждая запись — один элементарный шаг: не более двух частиц. Суммарные реакции раскладываются на шаги
# с общей группой (group) и итоговым уравнением (education.summary). Проверка при загрузке:
# сохранение атомов и заряда, валентности продуктов, баланс итогового уравнения, сумма шагов = итог.
#
# mechanism: chain — радикальная цепь: шаги повторяются разное число раз, поэтому сумма шагов
#   с итоговым уравнением не сравнивается (проверяется баланс каждого шага и самого итога).
# smarts — reaction SMARTS с картой атомов (:1, :2 …): карта говорит, какой атом куда переходит.
#   Диалект NERV: заряд, не указанный в шаблоне реагентов, означает «заряд 0»;
#   Dn — число связей атома, Hn — число соседей-водородов; водороды пишутся явно ([H:2]).
# activationEnergy — кДж/моль (игровая шкала: радикальные шаги ускорены, чтобы пламя шло за секунды
#   экранного времени; инициирование по-прежнему требует искры), deltaH — кДж/моль (реальные теплоты образования, газ).
# rate — игровой коэффициент темпа: вероятность за проверку при очень высокой температуре.
